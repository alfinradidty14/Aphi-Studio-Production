Koneksi Database Cloud Multi-Perangkat

Hubungkan proyek Anda ke database cloud (seperti Supabase atau Firebase) agar seluruh kru di lapangan dapat mengakses dan memperbarui data secara real-time dari HP masing-masing.

Konfigurasi Database Cloud

💡 Panduan Gratis 2 Menit:

  1. Buka supabase.com dan buat akun gratis.
  2. Klik New Project, lalu buka menu Project Settings → API.
  3. Salin Project URL dan anon / public key ke form di samping.
  4. Klik Simpan Konfigurasi, dan seluruh data proyek Anda akan tersinkronisasi di cloud secara aman.
